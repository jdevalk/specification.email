# Contributing

Corrections and additions are welcome.

Three rules govern the corpus:

1. Cite an authoritative source for every requirement.
2. Describe observable outcomes, not one provider's implementation.
3. Use requirement status honestly: required, recommended, optional, or avoid.

Run `npm run build`, `npm run check`, `npm run mcp:typecheck`, and `npm run mcp:dry-run` before opening a pull request. Material content changes need a dated entry under `src/content/changelog/`.
