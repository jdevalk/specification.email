title: Browser-native WebMCP tools
date: "2026-10-16"
type: added
relatedSlugs: [dkim-signatures]
---

Pages now register five [WebMCP](https://webmachinelearning.github.io/webmcp/) browser tools (`search_spec`, `list_topics`, `get_topic`, `open_search`, `open_checklist`), so an in-browser AI agent can search and read the specification without going through the remote MCP server. The tool bundle loads only when the browser exposes `modelContext`; tool metadata is type-checked against the WebMCP spec at build time, topic lists are paginated, and long pages are served with line offsets.
